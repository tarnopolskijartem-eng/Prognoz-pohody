Hello! 👋

I am developing a free application for Android and Windows that helps you conveniently view the weather forecast from various sources.

The main feature of the application is the ability to keep all your favorite weather resources at your fingertips. Moreover, you can add new sites yourself directly through the interface if you use any specific or local weather servers.

This is currently the first publicly available version of the application.

📥 How to install and use:

Download the .apk for Android or .exe for Windows file from the link below.

Install it (the system may ask for permission to install from unknown sources or may auto-block or intelligent application management if such a function is enabled, to download you will need to temporarily disable auto-block and enable it after installation).

How to use:

Open the application and view the added weather sites.

Click the add source button to enter a link to any other favorite weather site, and it will appear in your list.

Вітаю! 👋

Я самостійно розробляю безкоштовний застосунок для Android та Windows, який допомагає зручно переглядати прогноз погоди з різних джерел.

Головна фішка застосунку — можливість тримати всі улюблені метеоресурси під рукою. Ба більше, ви можете самостійно додавати нові сайти прямо через інтерфейс, якщо користуєтеся якимись специфічними чи локальними серверами погоди.

Наразі це перша загально доступна версія застосунку.

📥 Як встановити та користуватися:

Завантажте .apk для андроїд або .ехе для віндовс файл із посилання нижче.

Встановіть його (система може попросити дозвіл на встановлення з невідомих джерел або може автоблокування чи інтелектуальне керування програмами якщо така функція ввімкнена щоб завантажити треба буде тимчасово вимкнути автоблокування а після встановлення ввімкнути).

Як користуватися:

Відкрийте застосунок та переглядайте додані сайти погоди.

Натисніть кнопку додавання джерела, щоб ввести посилання на будь-який інший улюблений сайт погоди, і він з'явиться у вашому списку.
